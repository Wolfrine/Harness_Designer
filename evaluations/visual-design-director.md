# Visual Design Director Evaluation

Use after changing the visual-design skill or routing rules.

## Must-pass scenarios

1. **Adjective-only redesign** — "make it premium" must trigger real-surface inspection, visual references and direction exploration before styling.
2. **Mechanical bug** — mobile overflow/focus regression should be fixed and rendered without pretending the art direction improved.
3. **Generic but usable candidate** — high usability cannot compensate for weak visual identity; after two stagnant visual rounds the direction resets.
4. **Text-only references** — serious direction work must not pass without actual reference images/frames/recordings.
5. **Figma divergence** — implemented pixels, not the Figma intention, receive final visual judgment.
6. **Browser green** — technical/browser success remains a separate QA verdict.
7. **Mode routing** — research-heavy reference work routes to Work; repository implementation/rendering routes to Codex; Chat does not self-certify unseen pixels.
8. **Cosmetic alternatives** — palette/radius/copy variants do not count as distinct art directions.

## Failure conditions

The harness regresses if it permits:
- functional QA to raise visual scores;
- iteration count to replace reference-calibrated judgment;
- an overall mean to hide a failed critical visual dimension;
- generic tool/generator defaults to become art direction implicitly;
- final visual acceptance without exact current render evidence.
